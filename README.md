# 积水夜跑 · Puddle Night Run

雨夜里，一个提着灯笼的女孩在积水上奔跑。每一步都踩出涟漪和水花，积水下面浮现出另一个世界——以及水里的"另一个她"：她会慢半拍、停下回头看你、跑远走丢……停下来，用灯笼照一照水面，她才会回来。

**在线体验**：https://xianxie6.github.io/puddle-night-run/

## 操作
- `↑` 起跑（同时开启声音），方向键 / 鼠标控制方向，`空格` 停下
- `R`：立刻让倒影开始"不听话"
- `?auto`：自动奔跑演示；`?render`：离线逐帧渲染（需配合 `serve.py` 保存到 `recordings/`）

## 本地运行
```bash
python3 serve.py   # 打开 http://localhost:8765
```

## 技术
three.js（CDN）· 自定义水面着色器（涟漪、反射、灯笼光、水下分层视差）· 骨骼动画（Blender 烘焙，脚本见 `blender/`）· WebAudio 程序合成踩水声。
